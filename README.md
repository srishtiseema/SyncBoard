# 🚀 SyncBoard

SyncBoard is a collaborative project management and task organization platform designed to help teams manage projects, track progress, and collaborate efficiently. The project provides a centralized workspace where users can organize tasks, manage project structures, and maintain project-related data.

## 📌 Features

- Team collaboration workspace
- Project and task management
- Database-driven backend
- SQL schema and database scripts
- Prisma ORM integration
- Organized backend architecture
- Easy database setup and maintenance

## 🛠️ Tech Stack

### Backend
- Node.js
- Prisma ORM
- SQL Database

### Database
- SQL
- Prisma Schema

### Development Tools

## 📁 Folder Description

### Backend/Prisma

Contains the backend database configuration and Prisma-related files.

- **Structure** – Database schema and project structure.
- **Lobby** – Database/model configuration related to lobby or workspace management.
- **sql** – SQL scripts used for creating or updating the database.
- **Delete_cascad.sql** – SQL script for implementing cascading delete operations.
- **lock.toml** – Prisma dependency lock file.

### .vscode

Contains Visual Studio Code workspace settings and configuration files.
